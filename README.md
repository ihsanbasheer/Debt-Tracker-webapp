# DebtTracker Web App 
A simple and intuitive web application built with Flask and Python to help users track and manage their debts. The app uses SQLite for data storage, allowing users to log debt amounts, payment history, and monitor progress. Visualizations powered by Matplotlib provide insights into debt reduction over time, while a clean and responsive interface is crafted using HTML and CSS for ease of use.

# Features

 * Developed a Flask-based web application to help users track debts and owed money.
 * Integrated SQLite database for efficient storage and retrieval of debt-related information

 * Utilized Matplotlib for data visualization, providing users with insights into their financial transactions.
 * Included user authentication to ensure data privacy and security.
